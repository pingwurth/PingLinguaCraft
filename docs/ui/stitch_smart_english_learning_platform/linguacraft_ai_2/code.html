resonance

n. 共鸣 · 回响

源自拉丁语 resonare（回音震彻）。在文人笔致中，不仅指物理声学之共震，更专指言辞或思绪穿透纸背、与阅者神智相契合的深邃心境。

修辞阶级 典雅升华级 (Literary Tier 1)
history_edu 原典对镜 · 笔力拆解

“Great prose evokes an emotional resonance that outlives its ink.”

“上乘文章所激荡之神思回响，历久弥新，终能超拔于纸墨痕迹之外。”

《文心雕龙 · 声律》之鉴

刘勰云：“夫立言之道，微言寄意，余韵绕梁。” 此处 resonance 即承托这种“余韵不绝、扣人心弦”的修辞力度。

仿写核心构架 (Syntactic Bone)
[Subject] evokes a [degree] resonance that [consequence]

用于从具象实体、技术力量或个人经历，跃迁到形而上的精神回响。

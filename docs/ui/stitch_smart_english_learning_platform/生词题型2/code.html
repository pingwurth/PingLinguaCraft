deliberate

adj. /dɪˈlɪb.ər.ət/
v. /dɪˈlɪb.ə.reɪt/
balance 词源·权衡之理

源自拉丁语 deliberare（仔细称量、慎思），由 de-（全然、彻底）+ libra（天平、磅秤，同 Libra 天秤座）化合演变而来。

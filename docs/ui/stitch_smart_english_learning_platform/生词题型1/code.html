文脉对仗赏析

乔布斯在此处运用了经典的前后并列对偶（Antithesis）修辞：前半句中的 looking [forward] 与后半句中的 looking backwards 构成时间与方向上的镜像呼应。

“向前展望时你无法串联起生命的各个点滴，只有在向后回溯时才能发现它们彼此相连。” forward 既表示空间上的向前，亦比喻时间向未来的推进，在此语境具有哲理双关之妙。

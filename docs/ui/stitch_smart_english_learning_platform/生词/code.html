词源溯流 · 构词拓扑

日耳曼语族原生词缀
-ward / -wards

源自原始印欧语 *wert-（转动、朝向），在古英语中演变为形容词/副词后缀，表示“朝向特定方向或空间状态”。

backward back + ward 向后的；落后的
awkward awk + ward 笨拙的；偏离的
toward to + ward 朝向；向着目标
inward in + ward 向内的；内心的

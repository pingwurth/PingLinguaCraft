壹 · 句法骨架 · 伴随状语解构

原句的核心语法妙处在于现在分词短语 looking forward 与 looking backwards。它们在句中充当伴随状语 (Attendant Circumstance)，修饰谓语动词 connect，形象勾勒出主体在“向前眺望”或“回溯审视”的动作状态下进行心智连接。

【前半阕 · 否定预判】 Present Participle

“You can’t connect the dots looking forward”

否定前瞻逻辑：未来充满变数，任何预先设想的逻辑网格在未经验证前皆为悬空假设。

【后半阕 · 回溯明悟】 Attendant Modifier

“you can only connect them looking backwards”

唯有站上时间的高阶，回首每一个独立经历（dots），其因果经纬方如水落石出般贯通。
